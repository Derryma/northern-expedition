# Northern Expedition

Public collaboration space for building this game together.

## How to join

1. Fork this repository.
2. Create a branch for your work.
3. Add your files or code changes.
4. Open a pull request with a short description of what changed.

## Project status

This repository is just starting. Add game design notes, assets, prototypes, and source code as the project takes shape.

## Suggested folders

- `docs/` for game design notes and planning.
- `assets/` for images, audio, sprites, models, and other game assets.
- `src/` for source code.
- `tools/` for helper scripts.
